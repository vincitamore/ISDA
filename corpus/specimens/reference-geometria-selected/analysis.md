# reference-geometria-selected

**Role.** The hierarchical-reference specimen: document architecture as the dominant stratum, with a four-level heading tree (`#` through `####`) and deliberately short sections. `shape.heading-tree-depth` reads the tree.

**Topic and source.** A configuration reference for a fictional germination-rack scheduler, written for this corpus in the shape of a knowledge-base reference page: every setting its own heading, type-default-meaning bodies, one nested subsection to force real tree depth.

**Telos.** *Reference lookup: find one setting's type and default without reading anything else.* **Substrate:** public.

**Ledger.** Scored against the measured 1,659 bytes. Geometria-Selected dominant (41% of the core): the hierarchy is the artifact. Rhetorica-Selected minor (which settings earn a warning sentence). Everything else Stock, since a settings page should originate nothing.

**Measured.** Chunk median 4.0 words, the short-section extreme of the corpus; paragraph median 14.5 for the prose that remains.
