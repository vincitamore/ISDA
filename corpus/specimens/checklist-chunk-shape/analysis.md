# checklist-chunk-shape

**Role.** The task-file specimen: frontmatter, checkbox vocabulary (`[x] [/] [ ] [!] [>]`), short imperative items. It holds the short-chunk end of the layout spectrum on which `shape.chunk-length-median` separates genres.

**Topic and source.** A spring-planting task file for a fictional greenhouse operation, written for this corpus in the shape of a working task file: status frontmatter, phased sections, a blocked section, a notes paragraph.

**Telos.** *Coordinate remaining work: reading the file tells you what to do next and what is blocked.* **Substrate:** context, the fictional operation's shared knowledge. The items point; they do not teach.

**Ledger.** Scored against the measured 1,143 bytes. Rhetorica-Selected dominant (what made the list, what is marked urgent); Geometria-Selected (the phase and blocked structure and the checkbox states carry information). Content strata Stock.

**Measured.** Chunk median 9.0 words, the signature of a list genre. In block B (working markdown), emails run about 11.5 words per chunk, skill files about 35 and memory indexes about 53.
